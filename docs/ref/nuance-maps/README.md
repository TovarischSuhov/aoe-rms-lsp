# Минимальные карты проверки нюансов

Одна карта на слот nuance-rules: минимальный пример конструкции,
разобранной в PR слота, и описание того, что наблюдать в игре.
Карты детерминированы (без `start_random`): единственная переменная
между прогонами — то, что проверяется.

## Как проверять

1. Скопировать `.rms` в `resources/_common/random-map-scripts/`
   внутри установки AoE2DE.
2. Сгенерировать карту в skirmish (2 игрока) на указанных в карте
   размерах (обычно TINY и GIANT).
3. Сверить наблюдение с ожиданием из шапки карты; результат —
   в комментарий к issue слота.
