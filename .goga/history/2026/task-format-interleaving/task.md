## Description

На 078 (27 почти пустых секций, весь контент живёт в ветках if-цепочек)
нарушены оба инварианта:

- **INV1** — `parse(format(x))` ≠ `parse(x)`: дети цепочки печатаются до
  заголовков секций; standalone-команды, разделённые в оригинале
  заголовком `<SECTION>`, при репарсе становятся скобочными атрибутами
  предыдущего `create_*` (дети `elseif` 36 vs 30, 19 vs 14).
- **INV2** — `format(format(x))` сходится только со второго прохода
  (pass3 == pass2).

Механика: парсер прикрепляет statement к секции, активной на строке
старта; conditional-цепочка, чей extent пересекает заголовки, целиком
живёт в одной секции — при печати её дети (включая записанные в
оригинале после заголовков других секций) выводятся до этих заголовков.

Направление фикса (из issue): **интерливинг** — заголовки секций внутри
extent'а цепочки печатаются в потоке детей на своих исходных позициях
(поток элементов уже сортируется по `Range.Start`); `endif`
синтезируется на истинном конце цепочки. Полный INV1 может не
восстановиться (следствие always-braces печати атрибутов + склейки
атрибутов парсером) — тогда остаточный класс документируется по
доктрине доков, без knownDivergent-механики для новых расхождений.

## Scope

**In scope:** `internal/format/rms.go` (elements/section/list/statement,

`invariants_test.go` (снятие или сужение knownDivergent), голдены

прочие backlog-хвосты.

  пределах достижимости модели; если остаточное расхождение неустранимо
  — оно задокументировано с живым репро в обоих доках. Файл снят с
  `knownDivergent`, либо остаётся с суженным, честным обоснованием.
- Прочие 77 файлов корпуса — без регрессий: `TestRMS_IdempotentCorpus`
  и репарс-сьют зелёные; сдвиги голденов — осознанные (каждый дифф
  объясним, без byte-noise).
- Пины на if-цепочки, пересекающие заголовки секций, добавлены
  (unit-тесты + fuzz-сид при новой находке).
- `make check` зелёный; `goga contract format` зелёный; corpus-гейт
  зелёный (в PR не запускается — прогонять workflow_dispatch на ветке).

## Risks and Constraints

- Тесты — только под memory cap (cgroup-песочница, CLAUDE.md).
- Редизайн стрим-модели — реальный риск для 77 зелёных файлов корпуса:
  регрессии ловит сьют, но каждый сдвиг голдена требует объяснения.
- `chainLast`/`replayChains` воспроизводят scope-дисциплину парсера —
  не дублировать логику, переиспользовать существующие replay-механизмы.
- knownDivergent не расширять молча: любое новое расхождение —
  находка + документирование, не маскировка.
