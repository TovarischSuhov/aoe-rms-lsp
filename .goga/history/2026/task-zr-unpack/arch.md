## Artifacts

Ячеечных артефактов (CODEMANIFEST / `.usages/`) нет. Единственный кодовый
артефакт — модификация `scripts/corpus-fetch.sh` (вне ячеек):

1. Ветка PK-magic: вместо WARN+skip — распаковка через python3 `zipfile`
   (stdlib; python3 уже используется режимом `--update`).
2. Извлечение только `.rms`/`.xs`; каждый внутренний скрипт — отдельная
   принимаемая запись сэмпла (индекс сэмпла + sanitized basename —
   уникальность гарантирует индекс).
3. Защита: не более 64 записей и 10 МБ на архив, без рекурсии во
   вложенные zip; только basename (без путей из архива).
4. Детерминизм: состав функции от запинненных SHA источников — тот же
   вход даёт тот же корпус.

Прогоны (не артефакты кода, артефакты проверки):

- сэмпл 100 — регрессия (состав изменится: архивы займут слоты);
- расширенный: `CORPUS_COUNT=300` → весь пул (~236 скриптов) под
  cgroup-песочницей; отчёт-раздел в docs/reviews/corpus-run-2026-09-09.md;
  дефекты — фиксы с тестами (политика PR #22/#24).
