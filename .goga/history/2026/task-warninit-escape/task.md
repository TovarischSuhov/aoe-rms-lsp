## Description

Устранить (или явно задокументировать как структурный эскейп) рост
вывода на `;` за проход при непарной `(` внутри блок-литерала
инициализатора вектора.

Репро: `vector A=(0,0)%{(0}`
- pass 1: `vector A = (0,0)%{(0};`
- pass 2: `…(0};;` — рост по проходам; format-on-save растит файл.

Механизм: непарная `(` держит баланс warnInit положительным → поиск
`,`/`;` на нулевой глубине не находит разделителя → `to` остаётся
extent-концом (включая съеденный expectSemi `;`) → cut захватывает `;`,
голова синтезирует свой.

Направление фикса: поиск разделителя, устойчивый к непарным скобкам
блок-литерала (учёт «литеральная» скобка не открывает стейтмент), либо
байт-точный дословный срез по образцу дегенеративного класса, либо
sentinel-отказ — по образцу решений #120 (вербатим-гейты
`xsMemberNames`/`degenerateRange`/`cutArgsEnd`).
