## Description

Репро (вход принят, форматирование обязано сходиться):
- `int A(){{while;{}}}` — каждый проход допечатывает пустой `{}`-блок;
  format-on-save растит файл бессрочно;
- `rule """""""""0000000\n({}rule {}` — наращивает `rule {\n}\n` за
  проход.

Механизм: дублирование пустого блока в пути печати bare-block /
while-verbatim (и rule-форма) — пустой блок с нулевой/вырожденной
экстент-геометрией печатается и из среза, и синтезом.

Фикс: локализовать дублирование в пути печати (печатать блок ровно один
раз: срез ИЛИ синтез, не оба), запинить оба репро сидами, прогнать
fuzz-бюджет до зелёного.

## Acceptance Criteria

- Оба репро: `XS(XS(x))` байт-идентичен, выход репарсится без
  error-диагностик; смежные формы (`while;{}` без обёртки, `do;{}`,
  rule-форма с валидным телом) — параметрический ряд зелёный.
- Пины дискриминируют: красные на пре-фиксной копии дерева.
- Сиды FuzzXS зелёные; fuzz-бюджет (≥2×60с, параллельность ≤2 под
  memory cap) без новых падений.
- `go test ./internal/format/... -count=1` под memory cap зелёный;
  `make check` зелёный; пины закрытых классов #120 не регрессировали.
