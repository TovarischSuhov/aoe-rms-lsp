## Description

Репро (вход принят парсером, выход обязан репарситься):
- `void A(){((0,0));}` → «void A() { (0,0)); }» — лишняя `)`,
  pass 2: «expected ;»;
- `void A(){(((0,0)));}` — деградирует так же.

Механизм: warnSlice открывает срез на внутренней `(` (диапазон
warning), хвост уносит внешнюю `)` группировки — её `(` теряется, срез
рождается несбалансированным.

Фикс: провести в warnVerbatim обход `calleeStart` (или эквивалентный
баланс открывающих/закрывающих), запинить оба репро (ряды `TestXS_*` +
сиды FuzzXS), прогнать fuzz-бюджет до зелёного.
