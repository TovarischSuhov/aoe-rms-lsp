# format-unclosed-block: незакрытый /* не должен порождать рост синтеза закрывателей

## Current State

`format.RMS` печатает секции через `section()`, который всегда синтезирует
закрыватель `</NAME>` после внутреннего списка. Незакрытый `/*` в парсере
(`rms.blankComments`) расширяет экстент комментария до EOF — оригинальный
закрыватель секции оказывается внутри комментария и парсером не виден.
Принтер встраивает комментарий (с проглоченным закрывателем внутри) в тело
секции, затем печатает синтезированный закрыватель после него; на reparse
синтезированный закрыватель уже виден, но комментарий всё ещё глотает
оригинал — ещё один синтез.

Воспроизведено на HEAD 2026-09-28 (ветка master, 659274b):

```
<LAND_GENERATION>
create_land F
/* trailing
</LAND_GENERATION>
```

каждый проход форматтера добавляет один `</…>`: len 90→109→128→147,
closers 2→3→4→5 — неограниченный рост вывода.

Нарушен инвариант ячейки — сходимость к фикспойнту
(`TestRMS_IdempotentCorpus` пинирует `format(format(x)) == format(x)`,
для knownDivergent — сходимость 3-м проходом). Класс родственный #94
(knownDivergent-фикспойнты), но механика другая: рост, не расхождение.

## Description

Фикс в `internal/format`: якорь хвостового комментария обрезается по
`limit` — симметрично `dropBefore`, экстент комментария не может
простираться за предел списка/секции, в которую он встраивается.
Синтез закрывателя после обрезанного комментария перестаёт удлинять его
на каждом проходе. Точная точка обрезки (`commentText`, `flushBefore`
или уровень `list`/`section`) — решение реализации; требование одно:
повторный формат не растит вывод.

## Risks and Constraints

- обрезка экстента меняет печатаемые байты комментария — надо отличать
  «хвост за пределом» от законного содержимого; страховка — golden-фикстура
  на точный вывод и корпус-прогон
- `commentText` уже несёт предрегулировку zero-col End (грабля case31,
  66c21ea) — новая обрезка обязана её не сломать; case31 остаётся зелёным
- у `statement()` параметр `limit` не используется (rms.go:652, hint
  gopls) — возможная точка входа обрезки, но не обязательство
- готча: lint-хук блочит коммиты молча; `.claude/`-симлинки не коммитить
