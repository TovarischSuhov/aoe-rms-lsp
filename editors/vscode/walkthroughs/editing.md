# Use completion, hover and signature help

- **Completion** (`Ctrl+Space`) offers the game's commands and
  attributes, XS functions and constants from the game install and your
  include closure, plus RMS boilerplate snippets.
- **Hover** documents a command or symbol from the game reference.
- **Signature help** (`Ctrl+Shift+Space` inside call parentheses) walks
  the arguments of XS functions.
- **Rename** (`F2`) renames a symbol across the whole include closure —
  including files that are not open; renaming a file in the explorer
  updates the `#include` directives of every referring file.
